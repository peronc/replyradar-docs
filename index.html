Reply Radar
Personal project · read-only

Find the threads worth answering. Draft the reply. You press send.

Reply Radar is a private tool I use to find public Reddit discussions where I can be useful, and to prepare replies in my own voice. It runs on my machine, it has one user (me), and it never publishes anything.

What it is

A personal, non-commercial assistant for reading public posts and writing reply drafts. It is not a hosted service, it is not sold, and it does not create accounts for other people. Its only purpose is to reduce the time I spend searching, so that the time I do spend in a thread is on the answer.

How it works

  1. Reads public posts

    Through Reddit's official Data API, with read-only access, from a short and fixed list of subreddits that I choose. No private messages, no profiles, no logged-out scraping.

  2. Scores and drafts

    Each post is scored for relevance, freshness and community rules. A language model writes two reply options; a separate check flags risks, including self-promotion where a community forbids it and missing disclosure where it is required.

  3. I review and publish manually

    I read the thread, edit or discard the draft, and post it myself in my browser. The tool has no publish button, by design.

What it does

  • Reads public posts and subreddit rules
  • Scores relevance, timing and risk
  • Drafts reply options for me to edit
  • Keeps a private history of my own drafts
  • Shows my own comment scores and visibility, with my consent

What it never does

  • Post, comment, vote, message or moderate via the API
  • Manipulate karma or circumvent bans and rate limits
  • Scrape logged-out pages or use multiple accounts
  • Train AI models on Reddit data
  • Sell, license or redistribute Reddit data

Data and privacy

  • Credentials: no Reddit password is ever stored. Access uses a revocable OAuth token, only with my explicit consent.
  • Content: only public posts and subreddit rules. No private messages, no sensitive inferences about users.
  • Processing: public post text is sent to a language-model provider solely to draft a reply. It is not used by this project to train models.
  • Retention: posts not linked to a saved opportunity are deleted after 90 days; request logs after 180 days. I can delete everything at any time.
  • Sharing: no analytics, no tracking, no third parties beyond the model provider used for drafting.

Scope and status

Single user, non-commercial, private instance. The project is under active development and its features change. This page describes what the tool is and is not; it is not an offer of service to third parties.
